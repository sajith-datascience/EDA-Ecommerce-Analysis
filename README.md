📊 Exploratory Data Analysis on Large-Scale E-Commerce Data
📌 Project Overview

This project focuses on performing end-to-end Exploratory Data Analysis (EDA) on a large-scale e-commerce dataset containing over 2 million records. The goal is to clean the data, explore customer ordering behavior, extract meaningful insights, and visualize patterns using Python.

📂 Dataset Information

Rows: ~2,019,501

Columns: 12

Domain: E-commerce orders

Data includes order time, products, users, reorder information, and cart activity.

🛠️ Tools & Technologies

Python

Pandas

NumPy

Matplotlib

🔍 Key Steps Performed

Loaded and explored the dataset (shape, info, data types)

Checked and handled missing values

Verified duplicate records

Performed data type conversions

Analyzed unique values and distributions

Applied groupby and aggregation operations

Created pivot tables for structured insights

Engineered time-based features (day of week, hour of day)

Segmented time into morning, afternoon, evening, and night

📈 Analysis & Insights

Order distribution across days of the week

Peak ordering hours during the day

User order frequency segmentation

Number of days between pre-order and order

Top 15 most popular products

Products added to cart distribution

Reorder analysis and top reordered products

📊 Visualizations

Bar charts

Pie charts

Histograms

Used visualizations to clearly represent user behavior, order trends, and product popularity.
